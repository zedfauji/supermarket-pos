# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** Phase 1 is subtraction (remove bar/pool routes/tiles/screens) plus a strings-only rebrand (D-02) — it introduces **zero new visual design**. This contract's job is to (a) pin the exact post-strip state of touched surfaces (HomeDashboard tile grid, removed-route navigation, app identity strings) against the design system that already exists, and (b) make sure nothing removed leaves a dangling/undefined UI state. No new tokens, components, or shadcn blocks are added.

|-------|-------|-------|

Exceptions: HomeDashboard nav tiles keep their existing `min-h-[160px] min-w-[160px]` touch-target size (pre-existing, Phase 32's touch-target sweep) — not a new exception introduced by this phase, restated so the executor doesn't "fix" it to the 8pt scale.

## Typography

Declared values are the subset of the existing system actually rendered on phase-touched surfaces (HomeDashboard grid, dialogs, badges). No new size or weight is introduced (D-02). Contract is capped at 2 weights: 400 regular / 600 semibold.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 regular | 1.5 |
| Label | 12px (`text-xs`) | 400 regular | 1.4 |
| Heading | 20px (`text-xl`, `font-heading`/Playfair Display) | 600 semibold | 1.2 |
| Display | Not used — this phase touches no full-bleed/marketing headline; omit rather than invent one |

Out-of-contract legacy detail (not part of this phase's typography commitment): tile labels currently render `text-sm font-medium` (500 weight) — a pre-existing systemic 3rd weight in the app that predates this phase and this phase does not touch, fix, or introduce. It is excluded from the Declared values table above and is not asserted as part of this phase's contract; the executor should leave it as-is and must not extend `font-medium` (500) usage to any other phase-touched surface.

## Color

No new color token is introduced. Existing 60/30/10 usage on phase-touched surfaces, restated for the checker:

| Role | Value | Usage |
|------|-------|-------|

Accent reserved for: HomeDashboard tile hover background, focus-visible ring on any keyboard-focused interactive element (tiles, logout button). No other accent usage is introduced.
