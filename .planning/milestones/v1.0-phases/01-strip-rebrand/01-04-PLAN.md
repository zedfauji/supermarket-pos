<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client-side route table | React Router's `&lt;Routes&gt;` is the sole gate deciding which page component mounts for a given URL — a missing catch-all previously let an unmatched path render nothing (not a security hole, but an undefined UX state) |
| Realtime channel subscriptions | `PoolRealtimeListener`/`WaitlistRealtimeListener`/`RappiRealtimeBridge` hold open Supabase Realtime channels; an orphaned subscription to a soon-to-be-dropped table is a client-side reliability issue, not a data exposure |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-08 | Denial of Service | Dangling Realtime subscription on a table dropped by a later SQL plan | medium | mitigate | This plan removes the client-side subscription BEFORE the corresponding SQL DROP runs in wave 3 (correct ordering per RESEARCH.md Pitfall 3), so the client never has an active channel pointed at a table that no longer exists |
| T-01-09 | Information Disclosure | An unmatched path previously rendered nothing (blank screen) rather than a defined redirect — not a leak, but an undefined state a malformed/stale bookmark could hit | low | mitigate | The new catch-all `&lt;Route path="*"&gt;` gives every unmatched path a defined, tested destination (`/home`, itself gated by `&lt;ProtectedRoute&gt;`) |
</threat_model>
