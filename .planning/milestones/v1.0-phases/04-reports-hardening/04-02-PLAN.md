Margin must use the cost at time of sale, not current catalog cost, so it stays correct after later deliveries change `inventory.cost_price`.

Purpose: REP-02's "product sales" report scope includes margin/profit — the underlying cost data already exists from Phase 3's receiving flow, this plan wires it into checkout and reporting without inventing a new capability.

Output: A forward migration adding the snapshot column and redefining `process_direct_sale_atomic` to write it; a Margin column on `ProductSalesPanel` and its Excel/PDF/CSV exports.
</objective>
