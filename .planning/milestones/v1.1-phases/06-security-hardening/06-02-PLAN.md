This plan does NOT extend those two edge functions — that work is deferred to Phase 7, which already opens both files for the unrelated `pool_tables`/DATA-02 fix, making it the lowest-diff bundling point. This is a conscious deferral decided during Phase 6 planning, not an oversight.
