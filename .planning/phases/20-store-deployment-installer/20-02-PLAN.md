requires a pre-ship script proving the built artifact actually contains what it should.

## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Build machine (local or self-hosted CI runner) `Cert:\LocalMachine\My` -> shipped `.cer` resource | only the public half ever crosses; the private key must never leave this store |
| NSIS elevated post-install hook -> target machine `Cert:\LocalMachine\Root` | the store-owner's machine's own trust store is being modified by the installer it's running |
| GitHub Release (public) -> browser download -> store machine | Mark-of-the-Web boundary — this is where SmartScreen evaluation is triggered, unrelated to signing correctness |
