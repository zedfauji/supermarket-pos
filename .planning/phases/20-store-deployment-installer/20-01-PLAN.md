## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Local dev/ops machine -> remote Supabase project (control plane) | `supabase` CLI calls carry a personal access token / linked-project session; deploy and secrets-set are privileged control-plane operations |
| `supabase/.env.secrets.production` on disk -> git | the file itself never crosses this boundary if `.gitignore` is correct; the risk is exactly a gitignore gap letting it cross |
| Remote secrets store -> edge function runtime | `Deno.env.get(...)` calls inside deployed functions; secrets never appear in client-side code or logs |
