Complete D-16/D-17's cutover: now that Plan 26-05 proved a real controlled client migrates cleanly to
the new update channel, strip `src-tauri/tauri.conf.json` to a generic, customer-agnostic placeholder
identity and remove the old `publish-tauri` job from `release.yml` — every active customer, including

be re-confirmed against the config it will actually guard from now on.

live, there is no fallback left if a customer's override file is ever missing or wrong; D-08's gate is
the only thing standing between a build and shipping generic/wrong identity to a real customer, so it
gets a fresh, real proof against the actual final state rather than inherited confidence from an
earlier proof against a different config.
Output: `src-tauri/tauri.conf.json` as a generic placeholder, `release.yml` with a single release path
(`sync-customers`), and a fresh, passing D-08 negative-path proof against that final state.
