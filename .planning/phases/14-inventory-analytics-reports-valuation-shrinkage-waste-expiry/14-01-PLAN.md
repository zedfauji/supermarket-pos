<objective>
Build the Valuation report (INVR-01) end-to-end as this phase's tracer slice: a shared
`computeInventoryValueAsOf` reconstruction function, a Supabase-backed query hook, a
`ValuationSection` widget (product rows + category subtotal + store-wide total + D-03 formula

Expiry-Loss, and Turnover (later plans, same phase) will extend and reuse.

inventory, priced consistently and auditably, and prove the "value as of date X" reconstruction
pattern D-04 requires both Valuation and Turnover to share.
Output: `queries-analytics.ts` (new file, `computeInventoryValueAsOf` + `useInventoryValuationReport`),
`InventoryAnalyticsPanel`/`ValuationSection` widgets, a new Reports-page tab, CSV export wiring.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Reports page (authenticated client) -> Supabase | `useInventoryValuationReport` issues client-side SELECTs against `inventory`/`stock_movements`/`products`; RLS + the page-level `view_reports` RBAC gate (`ReportsRoute`) are the actual enforcement boundary, not client-side checks. |
| Client -> local filesystem (CSV export) | `ExportButtons`/`useExportReport` write an exported file via Tauri's `save`/`writeFile`; cell values (product/category names) are untrusted-ish free text that could carry CSV formula-injection payloads. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|------------------|
| T-14-01 | Information Disclosure | `useInventoryValuationReport` (`inventory`/`stock_movements` SELECT) | medium | mitigate | Reuses the existing `stock_movements_select_manager_admin` RLS policy (manager/admin only) and the `ReportsRoute` `view_reports` RBAC gate already wrapping `/reports` — no new policy is introduced; verified indirectly by the existing RBAC coverage on `/reports` (no cashier-role path reaches this query). |
| T-14-02 | Tampering | CSV export of Valuation rows (Task 3) | low | mitigate | Reuses `rowsToCsv` (`src/shared/lib/exporters/csv.ts`), which already neutralizes CSV formula injection (CWE-1236) by prefixing risky leading characters — no new CSV serializer is written for `valuation-csv`. |
| T-14-03 | Repudiation | Valuation figures diverging silently from Product Sales margin without explanation | low | mitigate | D-03's mandatory tooltip explicitly states the two reports use different cost bases (current cost vs. point-of-sale cost snapshot), so a divergence is explained inline rather than silently confusing the owner. |
</threat_model>
