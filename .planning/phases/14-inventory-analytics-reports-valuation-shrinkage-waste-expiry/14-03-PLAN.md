<objective>
Build the Shrinkage/Waste (INVR-02) and Expiry-Loss (INVR-03) report sub-sections: a shared
`groupShrinkageByReason` pure function filtering the now-fully-tagged `stock_movements` ledger
(D-01's `expired` value landed in 14-02) by reason, valued at current cost (D-03), with pre-feature
rows explicitly bucketed as "unclassified" (D-02) rather than guessed at. Both sections attach to
the `InventoryAnalyticsPanel` composer built in 14-01.

Purpose: give the owner a reason-level breakdown of non-sale stock loss, with expiry losses
called out separately so waste/damage/correction figures aren't muddied by expiry.
Output: `groupShrinkageByReason` (pure fn), `useShrinkageWasteReport`/`useExpiryLossReport` query
hooks, `ShrinkageWasteSection`/`ExpiryLossSection` widgets, CSV export for both.
</objective>
