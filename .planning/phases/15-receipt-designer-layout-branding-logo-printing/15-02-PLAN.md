    In printer.rs, add `use image::imageops::FilterType;` and `use image::imageops::colorops::{dither, BiLevel};`. Implement `fn encode_logo_raster(png_or_jpeg_bytes: &[u8], target_width_dots: u32) -> Result<Vec<u8>, String>`:
    - Decode: `let img = image::load_from_memory(png_or_jpeg_bytes).map_err(|e| e.to_string())?;`
    - Compute the aspect-preserving target height: `let scale = target_width_dots as f32 / img.width() as f32; let target_height = ((img.height() as f32) * scale).round().max(1.0) as u32;`
    - Resize: `let resized = img.resize(target_width_dots, target_height, FilterType::Lanczos3);`
    - Grayscale: `let mut gray = resized.to_luma8();` (a `GrayImage` = `ImageBuffer<Luma<u8>, Vec<u8>>`)
    - Dither in place to exactly 2 values (0=black, 255=white) via Floyd-Steinberg error diffusion: `dither(&mut gray, &BiLevel);` — signature is `dither<Pix, Map>(image: &mut ImageBuffer<Pix, Vec<u8>>, color_map: &Map)`, `BiLevel` is a zero-sized struct implementing `ColorMap<Color = Luma<u8>>` (confirmed via docs.rs for image 0.25.10 — do not hand-roll this).
    - Compute `let width_bytes = (target_width_dots as usize).div_ceil(8); let height = gray.height();`
    - Build the 8-byte GS v0 header: `let mut out = vec![GS, b'v', b'0', 0, (width_bytes & 0xFF) as u8, ((width_bytes >> 8) & 0xFF) as u8, (height & 0xFF) as u8, ((height >> 8) & 0xFF) as u8];` — `xL/xH` is the little-endian byte-count of the width, `yL/yH` is the little-endian dot-count of the height; these are NOT the same unit and must never be swapped (RESEARCH.md Pitfall 3).
    - Pack 8 horizontal dots per output byte, MSB-first: for `y` in `0..height`, for `byte_i` in `0..width_bytes`, build one `u8` by iterating `bit` in `0..8`: `let x = (byte_i * 8 + bit) as u32;` — if `x < target_width_dots`, read `gray.get_pixel(x, y).0[0]`; if it equals `0` (dark after dither) set bit `7 - bit` in the output byte (a `1` bit prints); if `x >= target_width_dots` (past-the-edge padding on the last byte of a non-multiple-of-8 width) leave that bit `0`, never garbage. Push each packed byte onto `out`.
    - Return `Ok(out)`.

    Add `#[cfg(test)] mod tests { use super::*; ... }` at the bottom of printer.rs, copying the exact `use super::*;` / `#[test] fn name() { assert_eq!/assert! }` shape from `logger.rs:96-109`. Implement the 3 tests from behavior above by building each fixture as a small in-memory PNG (`image::RgbImage`/`DynamicImage::ImageRgb8(...)`, `.write_to(&mut std::io::Cursor::new(&mut buf), image::ImageFormat::Png)`) so the tests also exercise the real `image::load_from_memory` decode path, not just the packing math in isolation.
