<objective>
Wire the live, scan-time promotion evaluation into every cart-entry path (product grid click,
barcode-scan-to-search-then-select, the Product Peek window's Add-to-Cart relay, and loose-weight
entry) so a qualifying item shows its discounted price the moment it lands in the cart — client
display only, per PROMO-03 — and add the cart-line "X% off" visual indicator.

Purpose: this is the cashier-facing half of PROMO-03; Plan 01 already made the server the
authoritative recompute, so this plan's only job is showing the right number before checkout, using
Plan 01's `evaluateBestPromotion()` and Plan 02's `usePromotions()`.
Output: promotion-aware `cartStore.addItem`/`addWeightedItem` call sites, a discount badge on
`CartItem`, and the PROMO-03 E2E proof.
</objective>
